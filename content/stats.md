## What we track

Page views only — which pages get visited and which downloads get clicked. No cookies, no fingerprinting, no cross-site tracking. The counter script loads only after the site owner enables it, and the dashboard is public so anyone can audit the numbers.

## Live dashboard

The public stats dashboard appears here once the counter is enabled (see [analytics setup](https://github.com/10xdev4u-alt/cline-linux#analytics) — one ID in `hugo.toml`, no code changes).
